# 💻 IT Asset Management System (Java)
A Java-based IT asset management system for tracking company devices, assignments, and inventory status.



## Overview

A Java console application designed to simulate an IT department asset tracking system.

The application allows users to manage company devices, assign assets to employees, and monitor inventory status.


## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner


## Features

- View available IT assets
- Assign devices to employees
- Track asset status
- Manage inventory information


## Java Concepts Demonstrated

- Classes and objects
- Encapsulation
- Constructors
- Methods
- ArrayLists
- Conditional statements
- User input
